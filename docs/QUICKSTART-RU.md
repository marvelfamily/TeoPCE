# TeoPCE: инструкция

[Страница проекта](../README.md) · [English guide](USER-GUIDE.md)

Для **Catalog Manager 0.2.0-rc4** и программы **TeoPCE 0.9.13** на приставке. Менеджер создаёт каталог ваших игр: чужая коллекция, подписка на ИИ и API-ключ не нужны.

## Что понадобится

**PC Engine / CoreGrafx и Turbo EverDrive Pro**, рабочая SD с меню Krikzz и ваши игры. Для CD нужен ваш рабочий BIOS. Сначала убедитесь, что игры запускаются через штатное меню. Менеджер не скачивает игры, BIOS и прошивку, не обновляет картридж и не исправляет образы дисков.

Сохраните резервную копию карты, особенно `edturbo` с игровыми сохранениями и `00TEOPCE/user` с состоянием TeoPCE. Автоматическая копия менеджера охватывает только **TeoPCE.pce и 00TEOPCE**, а не всю карту. Для установки не нужно форматировать уже работающую SD.

Выключите приставку перед извлечением SD. Подключите карту к компьютеру через картридер; USB-подключение самого картриджа не требуется.

## 1. Скачать и открыть

На [странице RC4](https://github.com/marvelfamily/TeoPCE/releases/tag/v0.2.0-rc4) выберите архив менеджера для своей системы и полностью распакуйте его. Автоматический архив GitHub «Source code» предназначен для разработки.

**Mac:** откройте `TeoPCE Catalog Manager.app`. Сборка предназначена для Apple Silicon. Подпись локальная, нотарификации Apple пока нет. Если первый запуск заблокирован, проверьте источник и контрольную сумму; затем при наличии такого пункта используйте «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно». Отключать защиту macOS целиком не нужно. Готовой сборки для Intel Mac в RC4 нет.

**Windows:** запустите распакованный `TeoPCE Catalog Manager.exe`, не из окна ZIP-архива. Цифровой подписи Authenticode пока нет: Windows может предупредить о неизвестном приложении. Перед запуском проверьте источник и сумму. Сборка проверялась через эмуляцию x64 в Windows 11 ARM64; отдельная проверка на Intel/AMD Windows ещё нужна.

Устанавливать Python для готового приложения не требуется.

### Проверка архива

Скачайте `SHA256SUMS.txt` из того же выпуска и сравните полную сумму нужного архива.

На Mac, в Терминале:

```sh
shasum -a 256 TeoPCE-Manager-0.2.0-rc4-macOS-arm64.zip
```

В Windows PowerShell:

```powershell
Get-FileHash .\TeoPCE-Manager-0.2.0-rc4-Windows-x64.zip -Algorithm SHA256
```

## 2. Выбрать SD и подготовить каталог

В разделе **Your card** нажмите **Choose card…** и укажите **корень SD с папкой edturbo**. Выбирать саму `edturbo` или папку одной игры не нужно. Если карта определилась автоматически, проверьте путь.

Нажмите **Prepare collection**. Менеджер проверит файлы, ссылки на треки в CUE, подберёт сведения и читы, скачает доступные изображения. Для точного определения CD читаются все треки, поэтому большой каталог готовится дольше. В **Activity** отображаются реальные этапы. Карту пока не отключайте.

На этом шаге создаётся отдельный комплект **на компьютере**. На SD он ещё не устанавливается. Откройте **View skipped games & warnings** и проверьте причины пропусков.

### Папки и форматы

Игры могут оставаться в своих папках. Пример структуры, не обязательная схема названий:

```text
Корень SD/
├── edturbo/               штатные данные EverDrive, BIOS и сохранения
├── HuCard/Example.pce
├── CD/Example/
│   ├── Example.cue
│   ├── Track 01.bin
│   └── Track 02.bin
├── TeoPCE.pce             появится после установки
└── 00TEOPCE/              появится после установки
    ├── data/              каталог, изображения, сведения и источники
    ├── cheats/            пакеты читов
    └── user/              настройки и сохранённый выбор кодов
```

- HuCard: `.pce`. CD: `.cue` и **все** указанные в нём треки. Имена файлов и регистр должны совпадать с CUE.
- ZIP, 7z, CHD, CCD и M3U напрямую не поддерживаются. Сначала распакуйте или преобразуйте свои образы.
- `MODE1/2048` требует отдельно проверенного преобразования в raw-секторы. Менеджер сообщает об этом, но не меняет образ самостоятельно.
- Относительный путь игры: печатные ASCII-символы, меньше 128 байт. Предел — 1 200 кандидатов в каталог.
- SuperGrafx может определяться при сканировании, но скрывается на CoreGrafx; запуск этих игр в данном выпуске не поддерживается.
- Разные HuCard с одинаковым именем файла могут конфликтовать в штатных сохранениях. Такие случаи требуют осознанного переименования.
- Скрытые папки, папки с подчёркиванием в начале, `edturbo` и `00TEOPCE` исключены из обычного поиска игр.

## 3. Проверить и оформить коллекцию

В **Collection** доступны поиск, показатели заполнения и фильтр **Missing covers**. `Cmd+F` на Mac или `Ctrl+F` в Windows переводит в поиск, `Esc` очищает его.

Выберите игру: **Game card** показывает карточку и источник обложки; **Edit** позволяет исправить название, год, категорию, описание; **Cheats** показывает подходящие группы кодов.

Неизвестный год оставьте пустым. **Choose cover…** принимает PNG/JPG/JPEG. Исходную картинку сохраните до подготовки каталога. Для текста лучше использовать короткие английские описания: шрифт приставки ограничен, при преобразовании символы вне ASCII могут заменяться или исчезать.

После правок нажмите **Save edits → Refresh collection**, проверьте результат и только затем устанавливайте. Сохранение правки само по себе не меняет SD. Пока комплект не обновлён, установка недоступна.

### Что скачивается из интернета

| Данные | Источник |
| --- | --- |
| Названия, годы, разработчики, издатели | Встроенный снимок Libretro Database; неоднозначные сведения не выдумываются |
| Подходящие читы | Встроенная лицензированная база, сопоставление по содержимому игры |
| Обложки и скриншоты | Доступные изображения Libretro Thumbnails; сохраняются в кеше компьютера |
| Полные описания | Ваш текст в Edit либо ваша готовая база через CLI; автоматически не скачиваются |
| Work offline | Встроенные сведения, кеш и ваши локальные изображения; недостающие картинки остаются отсутствующими |

Обложка есть не для каждого релиза. Недостающую можно добавить самостоятельно. Игры читаются локально и не загружаются на сервер; запрос картинки сообщает серверу название запрашиваемого изображения. Источники и пропуски видны в Activity и отчёте.

## 4. Установить и запустить

Нажмите **Install on card**, подтвердите установку и дождитесь **Installed and verified**. Не отключайте карту во время записи.

Установщик проверяет, что после подготовки не изменились игры и состояние TeoPCE, сохраняет и проверяет резервную копию прежних файлов, записывает новый комплект и проверяет результат. При обнаруженной ошибке выполняется попытка отката. Обрыв питания или извлечение SD требуют отдельной проверки карты и копии.

Безопасно извлеките SD средствами системы. Вставьте её в выключенную приставку, включите EverDrive и выберите **TeoPCE.pce** в корне.

ROM и папка `00TEOPCE` должны относиться к одной подготовке. Не смешивайте файлы каталогов разных версий и не используйте чужой готовый каталог для своего набора игр.

## Управление на приставке

Подсказки внизу экрана соответствуют текущему разделу.

| Экран | Кнопки |
| --- | --- |
| Список игр | Крестовина — выбор/страницы; **I** — карточка; **SELECT** — поиск/фильтры; **RUN** — запуск |
| Карточка | **I** — изображение; **II** — назад; **SELECT** — меню игры; **RUN** — запуск; вверх/вниз — текст; влево/вправо — другая игра |
| Меню игры | Запуск, избранное, читы, сведения о файле, возврат в EverDrive |
| Читы | **I** — переключение/инструкция; **SELECT** — параметры; **II** — отмена; влево/вправо — страницы; **RUN** — сохранить и вернуться |

Фильтры меняют только отображение, а не файлы. Если игра пропала из списка, сначала очистите фильтры.

## Читы

Менеджер автоматически подбирает пакеты. Вкладка Cheats на компьютере — просмотр; включение происходит **на приставке**.

1. Игра → **I** → **SELECT** → **CHEATS**.
2. Выберите группу, нажмите **I**, прочитайте её инструкцию.
3. Нажмите **RUN**, чтобы сохранить выбор и вернуться. Затем запустите игру.
4. Для отключения: **SELECT → All cheats off**. Все коды этой игры отключаются и сохраняются сразу; дополнительно нажимать RUN не нужно.

Выбор остаётся для следующих запусков, активные коды обозначаются в меню. **II** отменяет несохранённые изменения.

### Почему нет кодов или нельзя включить несколько

База содержит **1 177 целых групп для 347 точных релизов: 244 HuCard и 103 CD**. Это не все существующие версии игр. Для HuCard сверяется весь файл, для CD — точные байты CUE и все треки, включая аудио. Перевод, другая ревизия или изменённый CUE могут не совпасть. Переименовывать пакет ради принудительного совпадения нельзя.

Для **53 CD-релизов** важен ещё и относительный путь: от него зависят встроенные правила безопасного старта. При несовпадении менеджер показывает требуемый путь. Перенос установленной игры может затронуть профили; используйте отдельный свежий комплект или подготовленную миграцию.

Часть сочетаний блокируется из-за несовместимых защит запуска CD. Также у картриджа есть лимит 16 слотов: одна группа может занимать несколько, её нельзя обрезать наполовину. Уменьшите набор, если выбор не проходит проверку.

### HELD

**HELD означает известные проблемы или неподдерживаемые данные**, а не просто отсутствие проверки на приставке. По умолчанию такие строки скрыты. **Show held codes** показывает их для ознакомления.

У подходящих кодов после объяснения доступно **Accept risk** — включение на свой риск. Неподдерживаемые или некорректные данные разблокировать нельзя. Защита от несовместимых сочетаний остаётся. Скрытие HELD не отключает уже активные коды.

Некоторым кодам нужен определённый персонаж, режим или действие на титульном экране. Успешный запуск не доказывает работу эффекта на всех уровнях. При ошибке BIOS выключите коды, сравните со штатным запуском и укажите точную группу в отчёте.

**Import extra cheats…** принимает JSON-базу TeoPCE версии 1, а не произвольные файлы эмулятора. Импорт имеет приоритет над встроенной базой для того же содержимого; уже установленные пакеты и сохранённый выбор сохраняют приоритет при обновлении. Формат и источники: [CHEAT-LIBRARY.md](CHEAT-LIBRARY.md).

### Сохранения и IGM

На проверенной HuCard-конфигурации работают штатное IGM и быстрые сохранение/загрузка. Выход через IGM ведёт в **меню Krikzz**. Оттуда снова запустите TeoPCE.

В проверенной CD-конфигурации **нет штатного IGM и быстрых save states**. Обычные игровые/BIOS-сохранения — отдельный механизм. TeoPCE не добавляет оверлей для переключения CD-кодов во время игры.

## Добавление игр, обновление и резервные копии

Добавьте файлы на SD → **Prepare / Refresh collection** → проверьте → **Install on card**. Совместимые существующие профили и выбор читов сохраняются. Если после подготовки играли и состояние изменилось, подготовьте комплект заново.

Удаление, переименование и замена уже установленных игр не являются автоматической миграцией. При несовпадении прежней библиотеки сохраните копию и разберитесь с переносом; не удаляйте профили ради обхода проверки. Новую карту можно подготовить независимо. Прошивка EverDrive обновляется отдельно.

| В домашней папке компьютера | Назначение |
| --- | --- |
| `TeoPCE/prepared/` | Подготовленные комплекты и `REPORT.json` |
| `TeoPCE/metadata/` | Ваши правки, привязанные к пути подключённой карты |
| `TeoPCE/backups/installation-…/` | Прежние ROM/данные; после успеха — `RESULT.json` |
| `.cache/teopce-library/` | Кеш загрузок |

При смене буквы диска Windows или точки подключения может потребоваться учесть новый путь правок. Нужные metadata и backups сохраняйте. Старые prepared и кеш можно удалить при закрытом менеджере; без кеша картинки потребуется скачать заново.

**Восстановление:** закройте менеджер, скопируйте нынешние `TeoPCE.pce` и `00TEOPCE` в отдельное место, затем замените **обе** части парой из одной резервной копии. Не объединяйте поколения каталогов. Игры и `edturbo` не трогайте. При первой установке прежних файлов могло не быть — такая копия не содержит предыдущую версию. После копирования безопасно извлеките SD.

## Если что-то не получилось

| Ситуация | Что проверить |
| --- | --- |
| Карта не найдена | Выберите корень вручную; проверьте подключение и наличие `edturbo` |
| Игры пропущены | Отчёт: формат, ссылки CUE, ASCII-путь, скрытые папки, MODE1/2048 |
| Не запускается и из Krikzz | Образ, BIOS или карту; TeoPCE не чинит диски |
| Из Krikzz работает, из TeoPCE нет | Точное название/путь, версия прошивки, текст ошибки, отключены ли все коды |
| Нет читов | Не совпала точная версия/путь; обычный запуск остаётся доступен |
| Install недоступна | Сохраните правки и выполните Refresh до успешного завершения |
| Данные изменились | Подготовьте заново, не устанавливайте устаревший комплект |
| Нет года/картинки | Онлайн-подготовка или ручное добавление; неизвестный год оставьте пустым |
| Установка прервалась | Сохраните копии и staging-файлы, проверьте карту; не удаляйте lock при работающем установщике |

В [сообщении об ошибке](https://github.com/marvelfamily/TeoPCE/issues/new/choose) укажите версии, шаги, текст ошибки и результат штатного запуска. Уберите личные абсолютные пути из отчёта. Игры, BIOS, сохранения и полные архивы карт не прикладывайте.
