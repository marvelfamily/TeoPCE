# Посібник користувача TeoPCE

[Головна сторінка проєкту](../README.md) · [Візуальний огляд](TOUR.md)

**Посібники:** [English](USER-GUIDE.md) · [Deutsch](USER-GUIDE-DE.md) · [Français](USER-GUIDE-FR.md) · [Español](USER-GUIDE-ES.md) · [Italiano](USER-GUIDE-IT.md) · Українська

Інтерфейс застосунку наразі англійською. У цьому посібнику перекладено інструкції, а назви кнопок відповідають назвам у застосунку.

Для **Catalog Manager 0.2.0-rc6** і **TeoPCE 0.9.15**. Створіть власний каталог зі своїх ігор: для цього не потрібні ані колекція автора, ані підписка на ШІ чи ключ API.

![Бібліотека ігор на консолі у вигляді сітки обкладинок](images/console-grid.png)

*Інтерфейс консолі знято в емуляторі; менеджер показує приклад підготовленої колекції. [Походження знімків](SCREENSHOTS.md).*

## Перш ніж почати

Використовуйте **PC Engine / CoreGrafx + Turbo EverDrive Pro**, SD-карту, яка вже працює в рідному меню EverDrive, і власний робочий CD BIOS для ігор на CD. Дотримуйтеся інструкцій Krikzz щодо картриджа, меню та прошивки; TeoPCE не встановлює і не оновлює прошивку.

Зробіть резервну копію SD-карти, особливо збережень у `edturbo` та наявного стану в `00TEOPCE/user`. Автоматична резервна копія менеджера охоплює **TeoPCE.pce і 00TEOPCE**, а не всю карту. Залиште робочу файлову систему: для встановлення TeoPCE переформатування не потрібне.

Вимикайте консоль перед тим, як вийняти карту. Користуйтеся картридером комп’ютера; налагодження картриджа через USB не потрібне.

## Завантаження та запуск

Завантажте ZIP для своєї платформи зі [сторінки випуску RC6](https://github.com/marvelfamily/TeoPCE/releases/tag/v0.2.0-rc6) і повністю його розпакуйте. Автоматично створений GitHub архів вихідного коду призначений для розробки, це не самостійний застосунок.

Якщо вже встановлено RC4, зробіть резервну копію карти. Завантажте [TeoPCE.pce](https://github.com/marvelfamily/TeoPCE/releases/download/v0.2.0-rc6/TeoPCE.pce) і замініть однойменний файл у корені SD. Залиште на місці `00TEOPCE`, ігри та журнал відновлення, якщо він є. Якщо папки `edturbo/gamedata` немає, створіть її порожньою. Безпечно витягніть карту й запустіть TeoPCE. Для наступного оновлення каталогу використовуйте менеджер RC6.

**Mac:** відкрийте `TeoPCE Catalog Manager.app`. Ця версія призначена для Apple Silicon, має підпис ad hoc і не нотаризована Apple. Якщо перший запуск заблоковано, перевірте завантаження та контрольну суму, а потім, якщо доступно, виберіть в Apple **Системні параметри → Приватність і безпека → Все одно відкрити**. Не вимикайте Gatekeeper для всієї системи. Готової збірки для Intel Mac немає.

**Windows:** запустіть розпакований `TeoPCE Catalog Manager.exe`, а не копію у вікні перегляду ZIP. Застосунок не підписаний, тому Windows може показати попередження про невідомий застосунок. Перевірте джерело й контрольну суму, перш ніж вирішити, чи запускати його. RC4 протестовано через емуляцію x64 на Windows 11 ARM64; пізніша збірка Windows, розміщена на GitHub, також пройшла перевірку запуску. Повне ручне тестування розповсюджуваного бінарного файлу на Windows із процесором Intel/AMD без емуляції ще не проведено.

Для готових застосунків окрема інсталяція Python не потрібна. Щоб перевірити ZIP, порівняйте його повну контрольну суму з `SHA256SUMS.txt` із того самого випуску:

```sh
# macOS Terminal
shasum -a 256 TeoPCE-Manager-0.2.0-rc6-macOS-arm64.zip
```

```powershell
# Windows PowerShell
Get-FileHash .\TeoPCE-Manager-0.2.0-rc6-Windows-x64.zip -Algorithm SHA256
```

## Вибір і підготовка

У розділі **Your card** натисніть **Choose card…** і виберіть **кореневий каталог SD-карти, що містить edturbo**, а не сам `edturbo`. Якщо карту визначено автоматично, перевірте показаний шлях.

Натисніть **Prepare collection**. Менеджер шукає ігри, обчислює хеші вмісту, перевіряє посилання на доріжки CD, зіставляє метадані й чити та завантажує доступні зображення. Підготовка великих колекцій CD потребує часу, оскільки зчитуються всі доріжки. **Activity** показує фактичний перебіг роботи; не від’єднуйте карту.

Під час підготовки на комп’ютері створюється окремий пакет; на SD-карту нічого не встановлюється. Перед встановленням перегляньте **View skipped games & warnings**.

### Структура файлів і формати

Ігри можуть залишатися у своїх папках. Приклад нижче не є обов’язковою схемою іменування:

```text
SD root/
├── edturbo/               рідні дані EverDrive, BIOS і збереження
├── HuCard/Example.pce
├── CD/Example/
│   ├── Example.cue
│   ├── Track 01.bin
│   └── Track 02.bin
├── TeoPCE.pce             додається під час встановлення
└── 00TEOPCE/              додається під час встановлення
    ├── data/              каталог, зображення, відомості та атрибуція
    ├── cheats/            пакети для окремих ігор
    └── user/              налаштування та вибрані чити
```

- Використовуйте `.pce` або `.cue` разом з **усіма** доріжками, на які він посилається; назви файлів і регістр символів мають відповідати CUE.
- ZIP, 7z, CHD, CCD і M3U не підтримуються як прямі вхідні формати. Спочатку розпакуйте або перетворіть власні образи.
- Для `MODE1/2048` потрібне окремо перевірене перетворення на сирі сектори. Менеджер повідомляє про це, не переписуючи образ диска.
- Відносні шляхи до ігор мають складатися з друкованих символів ASCII і бути коротшими за 128 байтів. Підтримується не більше 1 200 кандидатів до каталогу.
- Файли SuperGrafx можуть бути розпізнані, але на CoreGrafx вони приховані; їхній запуск у цьому випуску не підтримується.
- Різні ревізії HuCard з однаковою базовою назвою можуть конфліктувати в рідному сховищі збережень; якщо повідомлено про конфлікт, назви потрібно обдумано змінити.
- Приховані папки та папки, назва яких починається з підкреслення, а також `edturbo` і `00TEOPCE` виключено зі звичайного пошуку ігор.

## Перевірка та редагування

![Колекція в Catalog Manager з вибраною грою та її відомостями](images/manager-collection.png)

У **Collection** доступні пошук, лічильники повноти та **Missing covers**. `Cmd+F` / `Ctrl+F` переводить фокус у пошук; `Esc` очищає його. Виберіть гру, щоб переглянути **Game card**, **Edit** або **Cheats**.

У Edit змініть назву, рік, категорію чи опис або виберіть обкладинку через **Choose cover…** (PNG/JPG/JPEG). Зображення має залишатися доступним для підготовки. Якщо рік невідомий, залиште поле порожнім. Використовуйте стислі англійські тексти: обмежений набір символів консолі нормалізує символи поза ASCII і може їх пропускати.

Натисніть **Save edits → Refresh collection**, перевірте результат ще раз і встановіть його. Саме редагування не оновлює карту; встановлення залишається недоступним, доки підготовлений результат не оновлено.

### Що доступно онлайн?

| Вміст | Як це працює |
| --- | --- |
| Факти й чити | Включені фіксовані знімки даних; обліковий запис не потрібен |
| Обкладинки та скриншоти | Доступні зображення Libretro Thumbnails завантажуються й кешуються локально |
| Текстові описи | Вводяться в Edit або беруться через CLI з вашого власного підготовленого джерела |
| Відсутні зображення | Чітко позначаються; за бажанням можна додати власну обкладинку |
| Робота без мережі | Лише вбудовані дані, кеш і локальні зображення; недоступні зображення залишаються відсутніми |

Не всі випуски охоплено повністю. Факти не вигадуються. Ігри зчитуються локально й не завантажуються на сервер; запити зображень повідомляють серверу назву запитуваної гри. Відомості про джерела та відсутні зображення наведено в журналі активності та звіті.

## Встановлення та запуск

Виберіть **Install on card**, підтвердьте запит і не від’єднуйте SD-карту, доки не з’явиться **Installed and verified**. Інсталятор перевіряє, чи змінилися ігри або стан застосунку, перевіряє резервну копію на комп’ютері, готує новий застосунок до встановлення та перевіряє встановлений набір. У разі виявлених збоїв він намагається виконати відкат; після від’єднання або втрати живлення все одно потрібно перевірити карту та резервну копію.

Безпечно витягніть карту засобами операційної системи, вставте її у вимкнену консоль, запустіть меню EverDrive і відкрийте **TeoPCE.pce** з кореневого каталогу. ROM і `00TEOPCE` мають походити з одного підготовленого покоління. Не змішуйте окремі файли каталогу та не використовуйте каталог, згенерований іншою людиною.

## Керування на консолі

У нижній частині екрана показано керування для поточного екрана.

| Екран | Керування |
| --- | --- |
| Список ігор | Хрестовина — вибір/перегортання сторінок; **I** — подробиці; **SELECT** — пошук/фільтри; **RUN** — грати |
| Подробиці | **I** — зображення; **II** — назад; **SELECT** — меню гри; **RUN** — грати; вгору/вниз — текст; ліворуч/праворуч — гра |
| Меню гри | Запуск, обране, чити, відомості про файл, повернення до EverDrive |
| Чити | **I** — перемикання/інструкції; **SELECT** — параметри; **II** — скасування; ліворуч/праворуч — сторінка; **RUN** — зберегти й повернутися |

### Перегляд, пошук і фільтри

У бібліотеці натисніть **SELECT**, щоб відкрити **FIND AND FILTERS**. Вгору/вниз вибирає параметр; ліворуч/праворуч змінює його. **I** застосовує налаштування або відкриває вибір назви, жанру чи літери для відповідних рядків. **II** скасовує зміни. **RUN** очищає вибрані фільтри; застосуйте зміни, щоб знову побачити всі ігри.

| Параметр | Доступний вибір |
| --- | --- |
| Title prefix | Введіть початок назви на екранній клавіатурі, до 12 символів; RUN запускає пошук |
| Library | Усі ігри, обране, нещодавно відкриті |
| Category | Оригінальні випуски, переклади, Homebrew, Museum, Tools / Tests, неліцензовані або всі категорії |
| Media | HuCard, CD-ROM або обидва носії |
| Genre | Вибір зі списку зі сторінками, наприклад Action, Adventure, Platform, Puzzle, RPG або Shoot'em Up |
| Letter | A–Z, назви, що починаються з цифри чи символу, через `#`, або всі літери |
| Region/lang | Японія, США, англійський патч, Other або всі |
| Cheats | Усі ігри або ігри з доступними для вибору читами |
| View | Список із зображеннями або сітка із шести обкладинок |
| Theme | Neon, Ember, Ice, Classic |

Фільтри поєднуються. Наприклад, виберіть **Original releases + HuCard + Action**. Звичайну бібліотеку впорядковано за алфавітом A–Z; Recently opened використовує порядок історії. У цій версії немає сортування за роком або видавцем. Фільтри змінюють лише показаний список і не переміщують файли. Натискання **II** у відфільтрованій бібліотеці очищає фільтри.

Вибрана назва показується над списком або сіткою; довгі назви переносяться на наступний рядок. У подробицях наведено носій, регіон, жанр, рік, якщо він відомий, і доступні опис та відомості про розробника й видавця. **I** перемикає між обкладинкою та скриншотом гри, якщо вони доступні; вгору/вниз прокручує текст, а ліворуч/праворуч перемикає гру.

Додавайте гру до обраного або вилучайте її через **Details → SELECT → Add/Remove favorite**. Зберігається до 64 обраних і восьми нещодавно відкритих ігор. Історія записує відкриті картки ігор, а не виміряний час гри. Після перезапуску TeoPCE вибирає найновіший доступний запис історії в невідфільтрованій бібліотеці. Налаштування вигляду та теми також зберігаються.

Короткі позначки описують поточний фільтр: `FAV` — обране, `OPEN` — нещодавні, `B*` — назви на B, `R:JP` — Японія, `R:US` — США, `L:EN` — англійський патч, `CH` — доступні для вибору чити. У ділянці назви також зазначено носій і регіон вибраної гри; `*` позначає гру в обраному.

**Details → SELECT** також відкриває дії для гри: запуск, обране, чити, відомості про файл і повернення до EverDrive. Відомості про файл допоможуть визначити вибраний запис каталогу та шлях під час повідомлення про проблему.

## Чити

Менеджер автоматично зіставляє пакети. На вкладці Cheats можна переглянути групи; активація відбувається **на консолі**:

1. Гра → **I** подробиці → **SELECT** меню гри → **CHEATS**.
2. Виділіть групу, натисніть **I** і прочитайте наявні інструкції.
3. **RUN** зберігає вибір і повертає назад. Запустіть гру.
4. **SELECT → All cheats off** одразу вимикає всі групи для цієї гри та зберігає зміни. Додатково натискати RUN не потрібно.

Збережений вибір залишається чинним; меню показує активні коди. **II** скасовує незбережені зміни вибору.

### Зіставлення, обмеження та HELD

Включена бібліотека містить **1 177 повних груп для 347 точно визначених випусків**. Для зіставлення HuCard використовується хеш повного файлу. Для CD враховуються точні байти CUE та всі доріжки, на які він посилається, зокрема аудіо. Інші ревізії, переклади або заново створені CUE можуть не збігатися. Не перейменовуйте пакет, щоб примусово досягти сумісності.

**Для 53 прив’язок CD також потрібен записаний відносний шлях**, оскільки від нього залежать скомпільовані правила запуску. Менеджер показує цей шлях, якщо він відрізняється. Переміщення встановленої гри може вплинути на збережений стан: використовуйте нове налаштування з резервною копією або виконайте обдуману міграцію.

Деякі комбінації мають несумісні механізми захисту під час запуску CD і блокуються. Картридж також має обмеження в 16 слотів; група може займати кілька слотів і зберігається цілком. За потреби зменште кількість вибраних груп.

**HELD означає відомі проблеми або непідтримувані дані**, а не просто «не перевірено на консолі». Ці записи типово приховані, але їх можна переглянути через **Show held codes**. Для придатних записів, утриманих через правила, доступно **Accept risk** з поясненням; некоректні або непідтримувані коди розблокувати неможливо. Перевірки комбінацій продовжують діяти. Приховування HELD не вимикає активні коди.

Інструкції можуть вимагати дії на титульному екрані, певного персонажа або режиму. Успішний запуск не доводить дію коду на кожному рівні. Якщо з кодом виникає помилка BIOS, очистьте коди, порівняйте запуск у рідному меню та повідомте точну групу й ревізію.

**Import extra cheats…** приймає бібліотеки TeoPCE JSON версії 1, а не довільні файли емуляторів. Явно імпортовані дані мають пріоритет над відповідними вбудованими; під час оновлення вже встановлені пакети й вибір мають пріоритет над обома. Див. [CHEAT-LIBRARY.md](CHEAT-LIBRARY.md).

### Збереження та IGM

Рідне IGM для HuCard і швидке збереження/завантаження випробувано на обладнанні власника. IGM повертає до **меню Krikzz**; запустіть TeoPCE звідти знову.

У перевіреній конфігурації CD **немає рідного IGM або швидкого збереження стану**. Звичайна підтримка збережень гри чи BIOS — окрема функція. TeoPCE не додає внутрішньоігрового накладання для перемикання кодів CD.

## Оновлення, зберігання та відновлення

Після додавання ігор: **Prepare / Refresh collection → перевірка → Install on card**. Наявні профілі та вибір зберігаються, якщо їхня ідентичність залишається дійсною. Після гри підготуйте колекцію знову, якщо стан застосунку змінився.

Видалення, перейменування або заміна встановлених ігор не є прозорою міграцією. Якщо попередня бібліотека більше не збігається, збережіть резервну копію та розв’яжіть питання міграції; не видаляйте профілі, щоб обійти перевірку. Нову карту можна підготувати незалежно. Оновлення TeoPCE не оновлює прошивку EverDrive.

| У домашній папці комп’ютера | Призначення |
| --- | --- |
| `TeoPCE/prepared/` | Підготовлені покоління та `REPORT.json` |
| `TeoPCE/metadata/` | Зміни редактора, прив’язані до шляху монтування карти |
| `TeoPCE/backups/installation-…/` | Попередні ROM і дані; `RESULT.json` після успішного встановлення |
| `.cache/teopce-library/` | Кеш завантажень |

Зберігайте потрібні зміни та резервні копії. Новий шлях монтування або літера диска Windows можуть вплинути на пошук змін. Старі підготовлені результати й кеш можна видалити, коли менеджер закрито; після видалення кешу знадобиться повторне завантаження.

Для відновлення закрийте менеджер, скопіюйте поточні `TeoPCE.pce` і `00TEOPCE` в інше місце, а потім **замініть обидва** парою з однієї резервної копії. Не об’єднуйте покоління. Ігри та `edturbo` не змінюйте. Резервна копія першого встановлення може не містити жодного з двох елементів застосунку й не може відновити попередню версію, якої ніколи не було. Після копіювання безпечно витягніть карту.

## Усунення несправностей

| Ознака | Наступний крок |
| --- | --- |
| Карту не знайдено | Виберіть її кореневий каталог вручну; переконайтеся, що карту змонтовано і вона містить `edturbo` |
| Ігри пропущено | Прочитайте звіт; перевірте формат, посилання CUE, шляхи ASCII, виключені папки та MODE1/2048 |
| Не працює і в рідному меню | Перевірте образ, BIOS і карту; TeoPCE не ремонтує образи |
| Не працює лише запуск через TeoPCE | Запишіть назву й шлях, консоль і прошивку, точний текст помилки та стан із вимкненими читами |
| Немає сумісних кодів | Точний вміст або потрібний шлях не збігся; звичайний запуск залишається доступним |
| Встановлення недоступне | Збережіть зміни й оновіть колекцію; підготовка для вибраної карти має завершитися |
| Карта або застосунок змінилися | Підготуйте знову; не встановлюйте старе покоління поверх новішого стану |
| Немає року чи зображення | Спробуйте підготовку онлайн або надайте власні дані; невідомий рік можна залишити порожнім |
| Встановлення перервано | Збережіть резервні копії та тимчасові файли встановлення, перевірте карту; ніколи не видаляйте файл блокування під час роботи інсталятора |

Скористайтеся [формою повідомлення про проблему](https://github.com/marvelfamily/TeoPCE/issues/new/choose): вкажіть версії, кроки, текст помилки та результат порівняння з рідним запуском. Приберіть особисті абсолютні шляхи. Не додавайте ігри, BIOS, збереження або дампи карти.

Ручні, платформні й апаратні перевірки RC6, які ще не проведено, перелічено в [RELEASE-STATUS.md](../RELEASE-STATUS.md). Атрибуцію та умови розповсюдження наведено в [THIRD-PARTY.md](../THIRD-PARTY.md); на підготовлених картах атрибуція метаданих і читів зберігається в `00TEOPCE/data`.
