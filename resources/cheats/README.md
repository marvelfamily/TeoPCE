# TeoPCE licensed cheat data

The library adapts Libretro Database contributors' data under CC BY-SA 4.0. The original files and their supplied credits are retained in upstream/. SOURCES.json records the pinned revision, original URLs, Git blob hashes, SHA-256 digests and license digest. LICENSE-CC-BY-SA-4.0.txt contains the license.

TeoPCE selected 1,177 complete matching groups for 347 exact-content releases, normalized labels and RAM aliases, and added stable IDs and CD startup constraints. The derived data retains CC BY-SA 4.0. TeoPCE-owned program code is MIT.

Reconstruction uses tools/import_libretro_cheats.py. The tests verify complete numeric-group equivalence and checksum integrity. These data checks establish source equivalence and serialization. Individual effects and new collections still need console validation.
